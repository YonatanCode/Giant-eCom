# Step 01 — Fetch live dealer data

**Goal:** turn Giant's existing Netherlands dealer locator data into a typed `src/data/stores-nl.ts`.
Standalone task; the finder UI (steps 02+) consumes the output. Read `00-overview.md` first.

## Status

**Complete.** Implemented `scripts/scrape-stores.mjs` and generated `src/data/stores-nl.ts` from Giant's live
locator endpoint. Verification passed with 225 dealers, exactly 57 official Giant Stores, and the expected
near-border warning for `Audise sprl`.

## Source

Use the same endpoint the live `/nl/stores` Google Maps locator calls after a location search:

```txt
POST https://www.giant-bicycles.com/nl/stores/dealers
```

The response already includes the fields we need: name, localized address, phone, email, website,
`Latitude`, `Longitude`, `IsGiantStore`, `StoreShortname`, marker icon, image, and `CampaignCodes`.
This replaces the older plan to parse `docs/store-finder/nl-stores.raw.txt` and geocode records one by one.

`docs/store-finder/nl-stores.raw.txt` can stay in the repo as a human-readable fallback snapshot, but the
generator should prefer the live locator endpoint because it is faster, gives authoritative coordinates, and
matches the current production map.

## Build `scripts/scrape-stores.mjs` (plain ESM, run with `node` — no deps)

Two modes:
- default: fetch all dealers from the endpoint, normalize to `StoreListing[]`, validate, and write
  `src/data/stores-nl.ts`;
- `--check`: re-read `src/data/stores-nl.ts` and validate it without network access.

### Endpoint request

Send JSON with a broad viewport and a non-empty search keyword so the endpoint returns the full all-dealer
locator set instead of the official-store default view:

```json
{
  "latitude": 52.132633,
  "longitude": 5.291266,
  "keyword": "Nederland",
  "NE_lat": 90,
  "NE_lng": 180,
  "SW_lat": -90,
  "SW_lng": -180,
  "campaigncodes": [],
  "onlyGiantStores": false
}
```

Use a descriptive `User-Agent` and `referer: https://www.giant-bicycles.com/nl/stores`.

### Normalization

- Parse `AddressLocalized` into `street`, `postcode`, `city`, `province`.
- Normalize whitespace and websites (`www.example.nl` → `https://www.example.nl`).
- Compute `slug` via the shared slug rule from `00-overview`, appending `-2`, `-3`, … on collisions.
- Set `isGiantStore = Boolean(IsGiantStore) || tags.includes("Giant Store")`.
- Set `detailHref`: official stores use `/store/<slug>`; partners use normalized `website`, falling back to `"#"`.
- Preserve source casing for store names.

Known source quirks to handle explicitly:
- some `AddressLocalized` values repeat the street line before the comma;
- Belgian Audise has a four-digit postcode and province `FL`;
- Fixabike Renesse currently has no endpoint `State`, so use `ZE` for that city.

### Campaign codes → tags

Map the endpoint's `CampaignCodes` to the real tag taxonomy:

| Code | Tag |
|------|-----|
| `2`  | `Giant Store` |
| `3`  | `Giant B2B Lease` |
| `4`  | `Premium Retailer` |
| `5`  | `DCF Supreme` |
| `7`  | `DCF Premium` |
| `8`  | `DCF Essential` |
| `9`  | `E-bike Testcenter` |
| `12` | `E-bike certificaat` |

### Output — `src/data/stores-nl.ts`

Emit the `StoreListing` interface (exact shape in `00-overview`) and `export const nlStores: StoreListing[] = [...]`.
Pretty-print with a header comment: `// Generated by scripts/scrape-stores.mjs - do not hand-edit. Source: https://www.giant-bicycles.com/nl/stores/dealers.`

## Self-check — `node scripts/scrape-stores.mjs --check`

Re-reads `src/data/stores-nl.ts` (or validates in-memory before write) and **asserts** (plain `assert`, no
framework):
- record count is in the expected all-dealer range (currently 225; keep the guard broad at `200..280`);
- `isGiantStore === true` count is **exactly 57**;
- every record has non-empty `name`, `street`, `postcode`, `city`, `province`, `phone`, `slug`;
- all slugs unique;
- every `lat` in `50.7..53.6` and `lng` in `3.3..7.3` (NL bounds); log any outliers (a couple of
  near-border entries may be acceptable — surface them, don't silently drop).
- spot-print 3 known stores for eyeballing: `Giant Store Bennebroek`, `Giant Store Amsterdam`,
  `Giant Store Marco` (Maastricht) — name, full address, lat/lng.
